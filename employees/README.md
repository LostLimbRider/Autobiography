## Using Position Manuals

Each position manual includes:

- **Position Overview:** Brief description of the role
- **Core Purpose:** Primary mission contribution
- **Primary Responsibilities:** Detailed list of specific duties
- **Required Skills & Competencies:** Essential capabilities
- **Preferred Experience:** Ideal background and training
- **Time Commitment:** Hours per week/month
- **Reporting Structure:** Direct supervisor and relationships
- **Success Measurements:** Performance indicators and outcomes
- **Key Relationships:** Internal and external stakeholders
- **Authority & Decision-Making:** What this position can approve/decide
- **Policies & Compliance:** Relevant policies and requirements
- **Development & Support:** Training and professional development
- **Onboarding Checklist:** First-day through first-month tasks

## Generating Position Manuals

To regenerate or update position manuals:

```bash
python3 generate_positions.py /path/to/output/directory
```

Or use the default employees directory:

```bash
python3 generate_positions.py
```

The script will create or update all 42 position manual files with current information.

## Updating Position Information

To modify position data, edit `generate_positions.py`:

1. Locate the `POSITIONS` list
2. Edit the position dictionary (name, purpose, responsibilities, etc.)
3. Run the script to regenerate manuals
4. Review changes and commit
