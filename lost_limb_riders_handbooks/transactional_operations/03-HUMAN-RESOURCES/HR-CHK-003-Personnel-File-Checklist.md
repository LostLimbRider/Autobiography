## 1. Purpose

Employee records are separated into distinct files so sensitive information is not unnecessarily consolidated and so the organization can respond to lawful requests without overdisclosing.

## 2. File Structure

### File A — Organizational Employment Record (permanent/program file)

- Position authorization (HR-FORM-001)
- Job description
- Offer letter and acceptance (HR-FORM-004)
- Compensation worksheet and approval (HR-FORM-005)
- Employment/status changes
- Performance reviews (HR-FORM-007)
- Training records
- Acknowledgment of policies and handbook
- Separation records (HR-FORM-009)

### File B — Payroll File

- Payroll setup (HR-FORM-006)
- Direct deposit authorization (no full account numbers in public systems)
- Wage and time records (HR-TIME-001)
- Payroll registers (FIN-REG-004)
- W-2 records
- W-4 (federal) and Iowa W-4 (withholding records)

### File C — Confidential Medical / Accommodation File (separate)

- Medical information
- Disability accommodation records
- Workers’ compensation medical records
- FMLA-type records (where applicable)
- Access: HR + authorized individuals only; not disclosed except as required by law

### File D — I-9 Storage (separate, legally required)

- Form I-9 and supporting documents
- Kept separate from personnel and medical files
- Retention: later of 3 years after hire or 1 year after termination (confirm current rule)

### File E — Disciplinary File

- Written warnings (HR-FORM-008)
- Investigation notes
- Corrective action records
- Access: limited to HR, supervisor, and management

### File F — Separation File

- Separation notice (HR-FORM-009)
- Final payroll and final check records (HR-CHK-005)
- Property return and access revocation records
- Exit interview notes

## 3. Checklist

- [ ] Each employee has Files A, B, and D established at hire
- [ ] File C created only if medical/accommodation records exist
- [ ] I-9 stored separately from personnel file
- [ ] Medical file access restricted
- [ ] Completed records stored in restricted system (REC-REF-001); no completed records in public repository
- [ ] Retention per REC-MATRIX-001
