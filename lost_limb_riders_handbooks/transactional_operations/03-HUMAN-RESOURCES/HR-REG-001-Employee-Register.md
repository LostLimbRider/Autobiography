## 1. Purpose

The Employee Register assigns each employee an `EMP-YYYY-NNN` ID and tracks their employment record. Completed register details are confidential; the register lives in restricted storage.

## 4. Linkage

Each employee row cross-references the compensation worksheet (HR-FORM-005), payroll runs (PAY IDs in FIN-REG-004), time records (TIM IDs), and personnel file location. The register closes an employee’s row at separation with the final-payroll reference.

## 5. Confidentiality

This register is a completed record containing personal information. It is maintained in the restricted records system (REC-REF-001). The public repository contains only this template.
