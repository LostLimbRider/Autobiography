## 1. Purpose

The complete employee lifecycle, from the moment a position is needed to final payroll and record retention. Every transition is documented.

## 3. Documentation for Each Transition

| Transition | Document | Who Completes |
|------------|----------|---------------|
| Position need | HR-FORM-001 Position Authorization | Department head |
| Job description | HR-REF-001 (existing position manuals) | Executive Director |
| Compensation | HR-FORM-005 Worksheet + approval | Board (insiders) / ED |
| Recruitment | HR-SOP-002 + application records | HR/Recruiting |
| Interview | HR-FORM-003 Interview Evaluation | Interview panel |
| Selection | HR-SOP-003 record | Hiring authority |
| Conflict check | GOV-POL-004 disclosure | Candidate + Board/HR |
| Offer/acceptance | HR-FORM-004 Offer Letter | ED / Hiring authority |
| Onboarding | HR-CHK-002 checklist | HR + supervisor |
| Payroll setup | HR-FORM-006 | Payroll/Finance |
| Timekeeping | HR-TIME-001 | Employee + supervisor |
| Payroll | FIN-PROC-004 / FIN-CHK-001 | Finance |
| Performance | HR-FORM-007 | Supervisor |
| Separation | HR-CHK-004 + HR-FORM-009 | HR |
| Final payroll | HR-CHK-005 | Payroll/Finance |
| Records | HR-CHK-003 + REC-MATRIX-001 | HR/Records |

## 4. Employee ID

Each employee receives `EMP-YYYY-NNN` from HR-REG-001 at hiring. The ID appears on time records, payroll records, and personnel documents so the trail is traceable.
