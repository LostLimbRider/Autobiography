## 1. Purpose

This index points to the existing position manuals so the HR lifecycle can reference the right job description at each step.

## 2. Sources of Position Descriptions

- **Primary source:** the `employees/` directory at the repository root — 42 position manuals generated from `employees/generate_positions.py`.
- **Secondary source:** the Position Description Manual section of the Organization Handbook.
- See `employees/README.md` for the complete position list, department grouping, and regeneration instructions.

## 3. Using a Position Manual

Each position manual includes: position overview, core purpose, primary responsibilities, required skills, preferred experience, time commitment, reporting structure, success measurements, key relationships, authority and decision-making, policies and compliance, development and support, and an onboarding checklist.

The position manual supplies the **job description** required by the lifecycle (HR-EMP-001) once a position is authorized (HR-FORM-001).
