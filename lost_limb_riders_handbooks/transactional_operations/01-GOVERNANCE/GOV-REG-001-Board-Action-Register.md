## 1. Purpose

The Board Action Register records every Board approval, authorization, and resolution that creates or authorizes a transaction. It provides the authorization link in the audit trail.

## 2. Transaction IDs

Each Board action receives an ID: `BRD-YYYY-NNN` (e.g., `BRD-2026-001`). The Secretary assigns IDs sequentially.

## 5. Linkage

Each entry cross-references the transaction it authorizes (from the relevant register) and the minutes where it was recorded. Compensation approvals also reference the HR-FORM-005 worksheet.

## 6. Storage and Retention

The register is a governance record stored per REC-REF-001 and retained per REC-MATRIX-001 (Permanent).
