## 1. Purpose

Programs track revenue and expenses by program so the Board can see the true cost and sustainability of each program, and so grant/restricted funding is spent correctly.

## 2. Procedure

1. Each program has a defined budget (per FIN-PROC-009) and its own account/segment in the chart of accounts.
2. All revenue and expenses reference the program ID (PRO-REG-001) at recording time.
3. Costs are allocated across programs where shared (allocation basis documented per the accounting policies).
4. Restricted and grant funds are tagged per FIN-PROC-006 and tracked to closeout.
5. Monthly, program financials (actual vs. budget) are included in the reporting package (FIN-CHK-002).
6. Each program is reviewed regularly for viability; discontinued programs are closed in PRO-REG-001.

## 3. Records

Program records (budgets, revenue, expenses, evaluations) are retained per REC-MATRIX-001 and support Form 990 program service reporting.
