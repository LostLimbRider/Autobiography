## 1. Purpose

Completed each quarter before the payroll/compliance due dates (Apr 30, Jul 31, Oct 31, Jan 31). **Check each item; note completion date and initials.**

## 2. Payroll and Deposits

- [ ] All payroll runs completed and payroll register (FIN-REG-004) updated.
- [ ] Federal deposits (FICA, FIT) made per current schedule; EFTPS/Direct Pay confirmations saved.
- [ ] Iowa withholding deposits/remittance made per current frequency.
- [ ] Federal deposit schedule (monthly vs. semiweekly) verified against lookback rule.
- [ ] FICA wage base and rates confirmed for current year (2026: SS $184,500; 6.2% + 1.45% each).

## 3. Quarterly Filings

- [ ] Form 941 prepared, reviewed, and filed (or +10-day window used if all deposits timely).
- [ ] Iowa withholding return (44-095) prepared and filed.
- [ ] Iowa UI quarterly wage/report prepared and filed (file even if no wages).
- [ ] Confirmations/receipts filed with records.

## 4. State and Records

- [ ] Iowa new hires reported within 15 days (if any).
- [ ] Bank reconciliations completed for each month in the quarter (FIN-PROC-007).
- [ ] Registers updated for all activity in the quarter (FIN-REG / EVT-REG / PRO-REG / SAF-REG).
- [ ] Restricted funds reviewed and verified (FIN-PROC-006).
- [ ] Any taxable sales or games-of-chance activity identified; sales tax handled per CMP-IA-001 §7.
- [ ] Penalty notices (if any) escalated to Executive Director and remediated.
