## 1. Purpose

Annual compliance review, completed each August and presented to the Board. **Check each item; note completion date and initials.** Verify all figures against current guidance before signing off (CMP-PROC-001).

## 2. Federal

- [ ] Form 990/990-EZ/990-N filed for prior year (due May 15); confirmation receipt retained.
- [ ] Tax-exempt status confirmed in good standing (no revocation risk).
- [ ] W-2/W-3 filed; copies retained.
- [ ] 1099-NEC / 1099-MISC filed; copies retained; backup withholding rules confirmed.
- [ ] Form 940 (FUTA) filed; state UI credit claimed.
- [ ] Form 941s filed for all four quarters; deposits made per schedule (monthly vs. semiweekly verified).
- [ ] I-9s complete; retention schedule verified.
- [ ] All deposit accounts (EFTPS/Direct Pay) current; no penalty notices received.
- [ ] UBI review: any 990-T obligation? (confirm with CPA)
- [ ] Contribution acknowledgments issued per FIN-PROC-005 for all qualifying gifts.

## 3. Iowa

- [ ] Biennial report filed (odd-numbered years; Jan 1 – Apr 1). Next due: 2027.
- [ ] Iowa withholding (44-095) filed for all four quarters; year-end reconciliation done.
- [ ] Iowa UI quarterly reports filed for all four quarters; rate confirmed for current year.
- [ ] New hires reported within 15 days (test a sample).
- [ ] Workers’ compensation coverage in force; certificate on file; evidence of compliance available on demand.
- [ ] Sales tax: permits current; taxable activities identified; returns filed.
- [ ] Gambling/games of chance license current for any raffle/bingo activity.
- [ ] Professional fundraiser(s), if any, verified registered under Chapter 13C.
- [ ] Required postings current and displayed (CMP-IA-001 §9).
- [ ] Minimum wage confirmed ($7.25 Iowa floor; pay the higher of state/federal).

## 4. Records and Controls

- [ ] Registers current: expenses, donations, restricted funds, payroll, assets, events, programs, incidents (FIN-REG / EVT-REG / PRO-REG / SAF-REG).
- [ ] Bank reconciliations completed monthly; reviewer sign-off recorded (FIN-PROC-007).
- [ ] Restricted funds released/verified per FIN-PROC-006.
- [ ] File and store records per REC-MATRIX-001; past-retention records destroyed per GOV-POL-003.
- [ ] Internal control thresholds confirmed current (FIN-CTRL-001).
