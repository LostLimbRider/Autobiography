## 1. Scenario

A hypothetical charity ride and picnic with an expected budget of $3,000 and expected revenue of $4,500. All figures are hypothetical.

## 2. Steps

- [ ] Event opportunity is identified and EVT-AUTH-001 (Event Authorization Form) is started.
- [ ] EVT-FIN-001 (Financial Feasibility) is completed; projected budget breaks even or better.
- [ ] Event is authorized at the correct level per EVT-POL-001 and FIN-CTRL-001.
- [ ] EVT-FORM-001 (Event Budget) is approved with income and expense categories.
- [ ] EVT-HR-001 staffing plan is completed; workers assigned and briefed.
- [ ] Permits, insurance, and contracts are verified before the event (EVT-FIN-001 checklist).
- [ ] Event revenue is logged and deposited per FIN-PROC-005/FIN-CHK-004.
- [ ] Event expenses are recorded against the approved budget.
- [ ] EVT-FORM-002 (Event Financial Summary) compares actuals to budget.
- [ ] EVT-CLOSE-001 (Event Closeout) is completed; surplus/deficit is reported and accounted.
- [ ] Event row is recorded in EVT-REG-001.
- [ ] Master Transaction Register (ADM-REG-001) is updated for event transactions.

## 3. Expected Result

The event lifecycle is fully traceable: authorization → feasibility → budget → staffing → execution → revenue → expenses → closeout → register. Surplus is accounted for; any loss is escalated.
