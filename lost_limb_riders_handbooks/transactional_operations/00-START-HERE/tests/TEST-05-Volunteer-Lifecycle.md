## 1. Scenario

A new volunteer applies to help at rides and events. All names and details are hypothetical.

## 2. Steps

- [ ] Volunteer completes VOL-FORM-001 (Volunteer Application).
- [ ] Screening per VOL-APP-001 is completed (references, role-appropriate checks).
- [ ] Volunteer is not classified as an employee (VOL-POL-001 — a volunteer is not an unpaid employee).
- [ ] Onboarding per VOL-CHK-001 is completed (orientation, safety briefing, release forms, role agreement).
- [ ] Volunteer is recorded in VOL-REG-001.
- [ ] Volunteer hours are tracked per the existing volunteer-hours form.
- [ ] If the volunteer claims mileage, the expense is reimbursed only per FIN-PROC-002 with documentation.
- [ ] No volunteer cash-handling role is created without the two-person rule (FIN-POL-002).
- [ ] Separation is recorded and the volunteer removed from active registers.

## 3. Expected Result

Volunteers are screened, onboarded, tracked, and — where they handle money or incur expenses — the same financial controls apply as for staff.
