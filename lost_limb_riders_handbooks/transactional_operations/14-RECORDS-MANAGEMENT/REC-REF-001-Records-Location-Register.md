## 1. Purpose

This register explains where actual completed records belong. It separates what may live in this public repository from what must live in the organization’s secure, restricted, or confidential records system.

## 2. Public Repository (Allowed)

Policies, procedures, checklists, blank forms, templates, job descriptions, schemas, compliance instructions, and generic examples. These contain **no personal data, no completed records, no account numbers, and no credentials.**

## 3. Secure Records System (Organizational, Off-Repository)

| Record Class | Primary Location | Access |
| ------------ | ---------------- | ------ |
| Board minutes and resolutions | Corporate records (encrypted) | Board/Secretary |
| Articles, Bylaws, determination letter | Corporate records (encrypted) | Board/Secretary/Treasurer |
| Financial records and ledgers | Finance drive (encrypted, access-controlled) | Finance staff |
| Bank account access and statements | Finance/Bank (restricted) | Authorized signers |
| Payroll records | HR/Payroll (restricted) | Payroll/HR |
| I-9 forms | HR restricted file (separate from personnel file) | HR only |
| Personnel files | HR restricted file | HR only |
| Medical/accommodation files | Confidential medical file (separate) | HR + authorized only |
| Donor records (name, contact, giving) | Development/Finance (restricted) | Fundraising/Finance |
| Participant records | Program files (restricted) | Program staff |
| Contracts with confidentiality clauses | Contracts vault (restricted) | Authorized officers |
| Incident/insurance/claim files | Risk files (restricted) | Risk/Insurance/Executive |
| Passwords, credentials, keys | Secret manager / locked vault | Authorized admins only |

## 4. What Never Goes in the Public Repository

- Social Security numbers
- Bank account and routing numbers
- Completed W-4s, I-9s, and payroll records
- Medical and disability information
- Private employee records
- Confidential donor and participant information
- Passwords and credentials
- Private contracts when confidentiality applies

## 5. Blank Templates Only

Where a form in this repository requests sensitive data, that request exists so the form can be printed/completed **and filed in the secure system**. Never commit a completed form to the repository. If a completed form is found in the repository, it must be removed immediately and reported per SAF-POL-002.

## 6. Review

The Records Compliance Officer reviews this register annually and updates locations when systems change.
