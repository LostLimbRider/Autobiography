## 1. Purpose

This register is the authoritative website-access classification source for canonical organizational documents. Repository visibility does not determine website publication.

## 2. Classifications

- **PUBLIC** — readable without authentication.
- **INTERNAL** — readable only by an authenticated, authorized user.

Any canonical document without an explicit entry in this register is classified **INTERNAL**. Authenticated authorized users may read the complete canonical corpus unless a higher restriction is established by an approved replacement to this register.

## 4. Migration Record

The prior website registry classified the two documents above as public and twelve selected records as internal. The public decisions are preserved explicitly here. The internal decisions are preserved by the repository-wide INTERNAL default, including canonical replacements where a legacy selected record was superseded. The prior website list does not define corpus completeness or future access authority.

## 5. Maintenance

Access changes follow ADM-PROC-002 (Change Control). Update this register in the same reviewed change as the affected publication decision. The production application consumes this register and must not maintain an independent access list.
