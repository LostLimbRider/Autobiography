## 1. Purpose

The Contracts Register tracks every contract and agreement so that terms, expirations, renewals, and obligations are never forgotten.

## 4. Procedures

- **New contract:** authorize per FIN-CTRL-001 before signing; file a copy; log here.
- **Renewal:** renewals due are reviewed 60 days before expiration.
- **Termination:** log termination date, reason, and final settlement.
- **Confidential contracts:** stored in the restricted records location (REC-REF-001); only the register entry is public.

## 5. Linkage

Each row cross-references related transactions (e.g., event, sponsorship, contractor, grant IDs) and the approval authority.
