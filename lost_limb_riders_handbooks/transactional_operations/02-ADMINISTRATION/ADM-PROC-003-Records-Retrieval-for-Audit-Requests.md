## 1. Purpose

To respond promptly, completely, and lawfully to audit, regulatory, donor (public inspection), and legal requests for records.

## 2. Request Types

- **Auditor/accountant request** — for the annual review or audit.
- **Regulatory request** — IRS, Iowa agencies, grantors.
- **Legal request / subpoena** — attorney or court.
- **Public inspection** — the organization’s three most recent Form 990s and application for tax exemption are generally required to be available for public inspection upon request (see CMP-IRS-001). Other donor and personnel records are not public.

## 3. Procedure

1. **Log the request.** Record requester, date, requested documents, and deadline.
2. **Scope.** Identify which transaction IDs and record classes are relevant using the Master Transaction Register (ADM-REG-001) and REC-REF-001.
3. **Retrieve.** Pull records from the correct secure location.
4. **Review for confidentiality.** Redact or exclude records protected by law (personnel, medical, donor, attorney-client, confidential contracts). Legal counsel directs redaction for legal requests.
5. **Authorize release.** Release only per applicable law and with Executive Director or Board authorization as appropriate.
6. **Deliver.** Provide a complete response on time; keep a copy of what was provided.
7. **Close.** Log the response; retain the request and response record per REC-MATRIX-001.

## 4. Tracing a Single Transaction

An auditor asking “why did this $X expenditure occur?” is answered via the audit trail:

```text
Expense record (EXP-2026-NNN) → Authorization (approval matrix level) → Purchase requisition
→ Receipt/invoice → Payment record (PAY) → Accounting entry → Closeout
```

All of these are retrievable if each was filed under its transaction ID at the time of the transaction.
