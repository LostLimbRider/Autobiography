## 1. Purpose

When law, regulation, policy, or organizational structure changes, the organization updates every affected document in a controlled way.

## 2. Change Triggers

- New or amended law or regulation (federal, Iowa, local)
- IRS or Iowa agency guidance changes
- Board-approved policy changes
- Organizational structure or staffing changes
- Audit, CPA, attorney, or insurance findings
- Lessons learned from incidents or events

## 3. Procedure

1. **Identify affected documents.** Using the source and verification log (CMP-REF-001) and compliance calendar (CMP-CAL-001), list every document that references the changed requirement: procedures, forms, checklists, compliance matrices, calendar entries, and indexes.
2. **Assess.** Determine whether the change is a clarification (no version change) or substantive (new version). Check for approval needs.
3. **Update.** Apply the change consistently across all affected documents. Do not fix one document and leave its twins.
4. **Version.** Increment versions per GOV-POL-001; set `Supersedes`.
5. **Document the change.** Record what changed, why, the source authority, and the date in the document’s revision history.
6. **Retire obsolete versions.** Retain prior versions (do not delete); update references.
7. **Notify.** Inform affected departments and update indexes.
8. **Verify.** Run the repository validation script to confirm no broken links or duplicated IDs.

## 4. Urgent Changes

Where a regulatory deadline makes normal approval impractical, the Executive Director may approve an interim change; the change is ratified at the next Board meeting.
