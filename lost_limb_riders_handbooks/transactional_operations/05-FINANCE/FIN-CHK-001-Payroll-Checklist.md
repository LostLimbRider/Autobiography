### Before the Run

- [ ] All time records collected and supervisor-approved (HR-TIME-001)
- [ ] New employees verified in payroll (HR-FORM-006)
- [ ] Rates verified against approved HR-FORM-005
- [ ] Changes (raises, status) verified and approved
- [ ] Exempt/non-exempt classification confirmed
- [ ] Overtime approved per HR-SOP-005

### Calculation

- [ ] Gross wages calculated
- [ ] Overtime at current required rate (non-exempt)
- [ ] Federal withholding per current W-4 tables
- [ ] Iowa withholding per current Iowa W-4/rules
- [ ] FICA rates current (verify annually)
- [ ] Employer taxes (FICA, FUTA, Iowa UI) current
- [ ] Deductions/benefits applied

### Approval and Payment

- [ ] Payroll approved per FIN-CTRL-001 (two approvers where practical)
- [ ] Test recalculation performed by second reviewer
- [ ] Payments issued on the scheduled pay date
- [ ] Direct deposit confirmed / checks delivered

### Post-Run

- [ ] Payroll journal entry posted
- [ ] Tax deposit made per current schedule (EFTPS/federal; Iowa per IWD/Revenue)
- [ ] Payroll register updated (FIN-REG-004)
- [ ] Master transaction register updated
- [ ] Payroll records filed per REC-MATRIX-001

### Quarterly/Year-End (as applicable)

- [ ] Form 941 filed by deadline (quarterly)
- [ ] Iowa withholding return filed/payment made
- [ ] Iowa UI contribution report filed and paid
- [ ] W-2/W-3 issued and filed by deadline (year-end)
- [ ] Reconciliation of payroll to tax filings completed
- [ ] Compliance calendar updated with confirmation references
