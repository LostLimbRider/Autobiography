## 1. Purpose

Every event is closed out: money accounted, personnel settled, incidents reviewed, records filed, and the event marked closed in the registers.

## 2. Closeout Steps

1. **Financial reconciliation.** All revenue recorded and deposited (FIN-CHK-004); all expenses approved and paid (FIN-PROC-002); restricted/grant funds reconciled (FIN-PROC-006).
2. **Complete EVT-FORM-002** (Event Financial Summary): actual vs. budget, net result, donations/sponsorships received, outstanding items.
3. **Personnel closeout.** Employee time approved and processed (FIN-PROC-004); contractor payments settled (CTR-FORM-004); volunteer hours recorded (VOL-POL-001).
4. **Incident review.** Review SAF-REG-001 for any incidents; confirm reports, follow-up, and insurance notification were completed (SAF-POL-002).
5. **Donor/sponsor follow-up.** Acknowledgments issued (FIN-PROC-005); sponsorship benefits delivered (FUND-SPON-001).
6. **Records.** Assemble the event file: authorization, budget, contracts, receipts, reconciliation, summary. File per REC-MATRIX-001.
7. **Register update.** Mark the event closed in EVT-REG-001 and ADM-REG-001; flag unresolved items.
8. **Lessons learned.** Note any improvements for the lessons-learned file (see EVENT-LESSONS-LEARNED).

## 3. Timing

Closeout occurs within a defined timeframe after the event (commonly 30 days) unless the Finance Director approves an extension.
