## **BEFORE OPENING**

- [ ] Site inspection completed (hazards, access, staging areas)
- [ ] Staff check-in completed against staffing plan (EVT-HR-001)
- [ ] Worker assignments confirmed; supervisor roles clear
- [ ] Safety briefing conducted and attendance recorded
- [ ] Emergency contacts posted and shared
- [ ] First aid / emergency kit location confirmed
- [ ] Exits and evacuation route confirmed
- [ ] Accessibility confirmed (ADA route, seating, services)
- [ ] Equipment checked and in place
- [ ] Communications plan in effect (radios / phones / channel)
- [ ] Weather check and contingency plan reviewed
- [ ] Client / organizer contact confirmed on site
- [ ] Incident documentation materials on hand (incident form)
- [ ] Cash / revenue controls in place (see EVT-REV-001) — registers, logs, two-person rule
- [ ] Permits posted / available for inspection

## **DURING EVENT**

- [ ] Attendance captured (counts or tickets)
- [ ] Worker time recorded (employees log HR-TIME-001; volunteers log hours)
- [ ] Incidents reported immediately (SAF-INC-001)
- [ ] Expenses tracked as incurred (FIN-EXP-001 / receipts collected)
- [ ] Revenue tracked per EVT-REV-001 (deposits, register drops, donation log)
- [ ] Equipment monitored (damage/loss logged)
- [ ] Periodic safety checks completed (schedule: ________)

## **CLOSING**

- [ ] Worker checkout completed (all accounted for)
- [ ] Time records collected from all employees (HR-TIME-001)
- [ ] Expense receipts collected and reconciled to log
- [ ] Cash/revenue reconciliation completed (EVT-REV-001) and deposit secured
- [ ] Incident reports reviewed (none / N#)
- [ ] Property check — equipment and supplies accounted for
- [ ] Site restoration / cleanup completed
- [ ] Client sign-off obtained where appropriate
- [ ] Post-event meeting or notes captured
