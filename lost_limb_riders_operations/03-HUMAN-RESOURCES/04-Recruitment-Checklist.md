## **Purpose**

Use this checklist for every recruitment. It ensures consistency, fairness, and a documented process.

## **Before Posting**

- [ ] Position authorized (HR-POS-001 approved; ID recorded)
- [ ] Job description finalized from position manual
- [ ] Compensation range approved (HR-COMP-001 / HR-PROC-002)
- [ ] Hiring panel identified (at least two people; no panelist with a conflict)
- [ ] Conflict-of-interest check completed for hiring panel

## **Posting**

- [ ] Posting approved and published through authorized channels
- [ ] Application instructions reference HR-APP-001
- [ ] EEO/non-discrimination statement included (Non-Discrimination Policy)

## **Screening and Interviews**

- [ ] Applications logged upon receipt; each assigned applicant number
- [ ] Minimum qualifications screen completed and documented
- [ ] Shortlist selected; interview slots scheduled (HR-INT-001)
- [ ] Interviews conducted by panel; evaluations completed per HR-INT-001
- [ ] Reference checks completed and documented
- [ ] Background check completed where required by policy (Volunteer/Employment screening policy)

## **Selection**

- [ ] Selection decision documented (candidate name, reason, panel consensus)
- [ ] Conflict check for final candidate completed
- [ ] Offer prepared (HR-OFR-001) and approved per FIN-CTRL-001
- [ ] Candidate notified; outcome recorded for all finalists (professional notification)

## **Records**

- [ ] Application materials retained for non-hired candidates per retention policy
- [ ] Hiring file assembled (authorization, posting, applications, evaluations, notes)
- [ ] Employee Transaction ID assigned (EMP-YYYY-###) and registered
