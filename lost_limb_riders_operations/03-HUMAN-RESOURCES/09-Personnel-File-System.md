## **1. Purpose**

This procedure defines what belongs in each employment-related file, who may access it, and how long it is kept. Sensitive information is deliberately separated so that no single file combines more sensitive data than necessary.

## **2. File Structure**

### 2.1 Personnel File (non-medical)

Maintained by the Executive Director / HR designee. Contains:

- Application and resume
- Offer letter and acceptance
- Position authorization
- I-9 eligibility verification (see 2.3 — original I-9 stored separately)
- W-4 and Iowa withholding (see 2.2 — original stored in payroll file)
- Signed policies and acknowledgments
- Emergency contact form
- Performance reviews (HR-PERF-001)
- Training records
- Disciplinary actions (see 2.5)
- Separation documentation

### 2.2 Payroll File

Maintained by Bookkeeper / payroll provider. Contains:

- Completed W-4 and Iowa withholding forms
- Direct deposit authorization
- Pay rate and compensation approval records
- Time records (HR-TIME-001)
- Payroll records and pay stubs
- Tax-related correspondence

### 2.3 I-9 File (restricted, separate)

Maintained by HR, physically/logically separate from personnel file:

- Form I-9 and copies of List A/B/C documents
- Access restricted per USCIS rules
- Retention: 3 years after hire or 1 year after termination, whichever is later

### 2.4 Confidential Medical / Accommodation File (restricted, separate)

Maintained by Executive Director in a locked/encrypted separate file:

- Medical documentation
- ADA accommodation requests and determinations
- Workers' compensation medical records
- Access on a need-to-know basis only

### 2.5 Disciplinary File

Maintained by Executive Director:

- Written warnings, corrective action plans
- Investigation records
- Termination documentation
- Appeals and outcomes
- Referenced from the personnel file but kept separate to protect the employee and the record

### 2.6 Separation File

Created at separation (HR-SEP-001):

- Resignation/termination records
- Final payroll checklist (HR-CHK-001, Checklist C)
- Access revocation log
- Property return log
- Exit interview (if conducted)

## **3. Access Rules**

- Personnel and payroll files: Executive Director, employee (their own file), and authorized staff on need-to-know.
- Medical file: Executive Director and, as required, the insurance/workers' comp administrator.
- I-9 file: HR designee and authorized inspectors per law.
- No file leaves the organization without authorization; copies are logged.

## **4. Retention**

Follow the Master Record Retention Matrix (CMP-RET-001). On retention expiry, destroy per the destruction methods in CMP-RET-001 and log the destruction.

## **5. Electronic Files**

Electronic personnel records are stored in approved, encrypted, access-controlled systems. Public cloud or public repositories are prohibited for these records.

## **6. Organization-Level vs. Employee-Level Records**

**Organization-level records** (employer registrations, tax rates, notices, payroll provider contracts, wage bands) are maintained in the HR organization file. **Employee-level records** are confidential per sections 2.1–2.6 above. Never mix the two.
