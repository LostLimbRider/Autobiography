## **Checklist A — Regular Payroll Run (each pay period)**

**Payroll ID (PAY-YYYY-###):** ____________  **Pay Period:** ________

- [ ] Time records collected from all supervisors
- [ ] All time records approved by supervisors
- [ ] New hires / terminations / rate changes applied to payroll system
- [ ] Compensation changes match approved HR-COMP-001 / HR-PROC-002
- [ ] Gross wages computed from approved time × approved rates
- [ ] Overtime verified as pre-approved
- [ ] Withholdings verified (W-4, Iowa, FICA) at current rates
- [ ] Employer taxes computed (matching, FUTA/SUTA) at current rates
- [ ] Payroll register reviewed line by line by Finance
- [ ] Executive Director approval obtained
- [ ] Employees paid on pay date
- [ ] Journal entry posted (wages by dept/program/event; liabilities; cash)
- [ ] Tax deposits made per schedule (federal + Iowa)
- [ ] Reconciliation completed (register = journal = liabilities)
- [ ] Records filed

## **Checklist B — Correction Payroll**

- [ ] Reason documented (overpayment / underpayment / missed change / other)
- [ ] Amounts verified against original payroll register
- [ ] Employee notified of adjustment
- [ ] Correction processed through payroll system (current-period or separate run as required)
- [ ] Tax implications reviewed (withholding adjustments, W-2c needs at year-end if applicable)
- [ ] Executive Director approval obtained
- [ ] Journal entry posted; reconciliation updated
- [ ] Records filed

Reviewed by: ______________  Date: ________

## **Checklist C — Final Payroll (Separation)**

- [ ] Final date of employment confirmed (HR-SEP-001)
- [ ] Hours worked through final date approved by supervisor
- [ ] Accrued/unused leave paid per policy (confirm policy with counsel)
- [ ] Deductions finalized (benefits, overpayment recovery if any)
- [ ] Final pay issued per Iowa law timing requirements (Iowa Code — confirm current rules)
- [ ] W-2 address and separation date updated
- [ ] Benefits terminated / COBRA considerations addressed per policy
- [ ] Journal entry posted; reconciliation updated
- [ ] Records filed

Reviewed by: ______________  Date: ________

## **Checklist D — Year-End Payroll**

- [ ] Final payroll of the year reconciled
- [ ] Year-to-date totals verified (gross, taxes, net) against quarterly filings
- [ ] W-2s prepared for all employees (current year) via payroll provider
- [ ] W-2 copies distributed to employees by the IRS deadline
- [ ] W-3 transmittal filed
- [ ] Final Form 941 / 940 reconciled and filed
- [ ] Iowa annual filings completed (IWD and Iowa DOR as required)
- [ ] 1099s for contractors reviewed (CTR-CHK-001)
- [ ] W-2c prepared where corrections are needed
- [ ] Payroll records archived per CMP-RET-001

Reviewed by: ______________  Date: ________

## **Variable-Rate Note**

Tax rates, deposit schedules, and deadlines change. Confirm current figures with the IRS, Iowa Department of Revenue, Iowa Workforce Development, and the payroll provider before each run and each year-end. Nothing here supersedes a current authoritative source.
