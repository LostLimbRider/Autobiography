## **Purpose**

This master checklist carries a new employee from acceptance to productive, compliant employment. Items marked **restricted** produce confidential records that are stored outside this repository (see REC-LOC-001).

## **EMPLOYEE IDENTIFICATION (restricted — personnel file)**

- [ ] Full legal name
- [ ] Address
- [ ] Contact information (phone, email)
- [ ] Emergency contact
- [ ] Start date
- [ ] Job title
- [ ] Department
- [ ] Supervisor
- [ ] Employment status (full/part/temporary/seasonal)
- [ ] Employee classification (exempt/non-exempt; salaried/hourly/stipend)
- [ ] Compensation (rate + pay frequency)
- [ ] Employee Transaction ID assigned (EMP-YYYY-###) and registered

## **REQUIRED TAX AND EMPLOYMENT DOCUMENTATION (restricted)**

- [ ] **Form W-4** completed (federal withholding). Review before first payroll.
- [ ] **Iowa withholding** documentation completed. Current Iowa form; confirm with Iowa Department of Revenue.
- [ ] **Form I-9** completed within 3 business days of hire, per USCIS rules. List A/B/C documents reviewed. Stored in the separate I-9 file (HR-FIL-001).
- [ ] **Direct deposit** authorization (if used) — bank account information stored restricted.
- [ ] **New-hire reporting** submitted to Iowa Workforce Development within statutory timeframe.
- [ ] **Payroll setup** completed in payroll system before the first pay period (HR-PROC-004).

## **ORIENTATION AND TRAINING**

- [ ] Position manual / job description reviewed
- [ ] Organization handbook reviewed (mission, values, policies)
- [ ] Employee handbook acknowledgment signed
- [ ] Safety orientation completed (09-SAFETY-RISK)
- [ ] Confidentiality policy acknowledged
- [ ] Conflict-of-interest disclosure completed
- [ ] Non-discrimination and harassment policy acknowledged
- [ ] Timekeeping training (how to complete HR-TIME-001)
- [ ] Expense / reimbursement training (FIN-EXP-002)
- [ ] Systems access set up (email, accounts, tools) — logged for revocation at separation

## **WORKPLACE SETUP**

- [ ] Workspace and equipment issued (log in asset register AST-001 if organizational property)
- [ ] Badge / keys issued (log for return)
- [ ] Emergency contact and evacuation procedures reviewed
